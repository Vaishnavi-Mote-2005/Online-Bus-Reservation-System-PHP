# Online-Bus-Reservation-System-PHP

A full-stack web-based Online Bus Reservation System developed using PHP, MySQL, HTML, CSS, and JavaScript.  
The system allows users to search buses, book seats, manage bookings, and simulate online ticket reservations through a responsive interface.

---

## 🚀 Features

### 👤 User Module
- User Registration & Login
- Search Available Buses
- Dynamic Seat Selection
- Bus Route Filtering
- Ticket Booking System
- Booking History
- Payment Simulation
- Responsive User Interface

### 🛠️ Admin Module
- Admin Login
- Add/Edit/Delete Buses
- Manage Routes & Seats
- View Bookings
- Manage Users

---

## ⚙️ Installation Steps

1. Install XAMPP Server
2. Copy project folder into:
```text
htdocs
```

3. Start:
- Apache
- MySQL

4. Import database file into phpMyAdmin

5. Open browser and run:
```text
http://localhost/project-folder-name
```
